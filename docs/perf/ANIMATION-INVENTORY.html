Can we do 60fps VFX / 30fps everything else? — YES.
  • VFX at 60fps: the fx-engine canvas already has its own rAF → keep it; the WAAPI combat flashes/trails (§3) are short one-shots that run at 60 naturally.
  • Other at 30fps: throttle the bar-ticker rAF to every-other-frame (HP/limit fills at 30fps — invisible). The sim is already 5Hz internally.
  • Caveat — CSS ∞ ambient (§1/§2): these run on the compositor at the display's refresh; you can't globally cap a CSS animation to 30fps. Hit the goal by cutting the ones you don't want and/or using steps(n) / coarser keyframes on keepers (visually ~30fps + cheaper). Pruning the always-on set is the real heat win either way.
